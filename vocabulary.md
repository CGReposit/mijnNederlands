## Starter list
| Dutch | English | Example |
|---|---|---|
| heten | to be called | Hoe heet je? |
| wonen | to live | Ik woon in Amsterdam. |
| werken | to work | Ik werk bij een universiteit. |
| boodschappen doen | to shop for groceries | Wie doet de boodschappen? |
| afspreken | to arrange / meet | Zullen we morgen afspreken? |
| gezellig | pleasant, sociable, cosy | Het was heel gezellig. |
| verhuizen | to move house | Ik ga volgende maand verhuizen. |
| overstappen | to change trains | Je moet in Utrecht overstappen. |
| vertraging | delay | De trein heeft vertraging. |
| tevreden | satisfied | Ik ben tevreden met de buurt. |

## University & admissions vocabulary
These terms are especially useful for Dutch university administration and admissions work.

| Dutch | English | Meaning / definition |
|---|---|---|
| student | student | A person enrolled in, or applying to, an educational institution. |
| bewerken | edit | To modify or change existing information. |
| ga naar | go to | A navigation command used to move directly to another section. |
| instellingen | settings | Options used to configure the system or application. |
| systeem | system | System-level functions and information. |
| help | help | Assistance or documentation for using the system. |
| studentendossier | student record / student file | The complete administrative record containing information about a student. |
| studentnummer | student number | The unique identification number assigned to a student. |
| zoeken naar | search for | To locate a student, programme, record, or other item. |
| studierichting | degree programme / field of study | The programme or academic field in which a student studies or applies. |
| algemene gegevens | general information | Basic information associated with a student or application. |
| aanvragen | applications / requests | Formal applications or requests submitted by or concerning a student. |
| toelating | admission | The process or status of determining whether an applicant may enter a programme. |
| aanvullende details toelating | additional admission details | Supplementary information concerning an applicant's admission. |
| betalingsgegevens | payment details | Information concerning payments, fees, or financial transactions. |
| toelating (VU) | admission (VU) | Admission information specifically relating to Vrije Universiteit Amsterdam. |
| functiebeperking | disability / functional impairment | A condition that may affect a student's ability to study or participate. |
| voorzieningen | facilities / accommodations | Support arrangements or provisions made available to a student. |
| inschrijving | enrolment / registration | The formal process of registering a student at the university or in a programme. |
| selectie en plaatsing | selection and placement | The process by which applicants are selected and allocated a place in a programme. |
| specialisaties | specialisations | Particular academic tracks or areas of concentration within a programme. |
| specialisatie aanvragen | specialisation applications | Requests or applications to enter a particular specialisation. |
| selectiecriteria | selection criteria | The standards or conditions used to assess and select applicants. |
| bijkomende vragen | additional questions | Supplementary questions associated with an application or admission assessment. |
| bijlagen | attachments | Documents or files attached to an application or record. |
| premasterassessment | pre-master's assessment | An assessment used to determine eligibility or requirements for a pre-master's programme. |
| controle toelaatbaar | admissibility check | Verification of whether an applicant meets the requirements to be considered admissible. |
| rappels | reminders / follow-ups | Notices sent to remind someone to take an outstanding action. |
| tonen | show / display | To display the selected item or document. |
| import | import | To bring data or a document into the system. |
| verwijderen | delete / remove | To remove an item, record, or attachment. |
| omhangen | reassign / transfer | In administrative software, to move or reassign an item to another record or category. |
| verificatie | verification | The process of checking that information or documents are correct or authentic. |
| goedkeuren | approve | To formally accept or confirm something as satisfactory. |
| communicatie | communication | Functions used for correspondence relating to the student or application. |
| genereer PDF | generate PDF | To create a PDF document from information in the system. |
| goedgekeurd | approved | Indicates that a document or item has been accepted. |
| documenttype omschrijving | document type description | A description of the category or type of document. |
| bestandsnaam | file name | The name under which an electronic file is stored. |
| inleesdatum | import date / date received | The date on which a document was read or imported into the system. |
| opmerking | remark / comment | An additional note or comment. |
| studieomschrijving | programme description | The description or name of a programme of study. |
| verzenddatum | dispatch / sent date | The date on which something was sent. |
| documentidentificatie | document identification | A unique identifier assigned to a document in the system. |
| documenttype | document type | The category assigned to a particular document. |
| toelaatbaar | admissible / eligible for admission | Meeting the requirements to be considered for or granted admission. |
| aanvullend | supplementary / additional | Added to something in order to complete or expand it. |
| bijkomend | additional / extra | Something extra that comes in addition to what is already present. |

> **Useful distinction:** *aanvraag* = application, *toelaatbaar* = admissible, *toelating* = admission, and *inschrijving* = enrolment. These are related stages, but they are not interchangeable.

1. Pick five words from one theme.
2. Say each word with its article where relevant: *de trein*, *het dorp*.
3. Write one short sentence per word.
